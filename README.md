# S&R Auto — Projeto Integrador VI-B

**Empresa:** Silveira & Ritter – Peças e Auto Center  
**Autor:** Denver Ritter  
**Etapa:** Primeira etapa — documentação e proposta do aplicativo  
**Plataforma prevista:** Android

## Apresentação

O S&R Auto é uma proposta de aplicativo móvel para aproximar a Silveira & Ritter de seus clientes, organizar informações de veículos e serviços e apoiar a administração com indicadores baseados nos dados registrados.

O aplicativo será projetado para funcionar com banco de dados local SQLite no próprio celular, inclusive sem conexão com a internet. Quando houver conexão, uma API permitirá sincronizar os dados entre os dispositivos autorizados.
